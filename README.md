# AI Platform Architecture Research

This repository contains the completed architecture-research package for evaluating AI platform foundations, reusable engines, security boundaries, integration seams, and migration paths.

The package includes the research findings and supporting artifacts under `research/`, plus safe workspace metadata. Cloned upstream source repositories were intentionally excluded: the entire `research/repos/` directory is absent from this repository. Credential-bearing local configuration was also excluded.

The findings are analysis artifacts, not production implementation, and were uploaded without modifying their contents.
